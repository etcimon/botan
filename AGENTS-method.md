# botan — Reading discipline

Analysis is cohesive prose grounded in this checkout. Anything not opened is marked unread
in place, never inferred from C++ Botan or from memory of an older pin.

A note is addressed to the **next change**: it names the area, locates responsibility as
`file:line`, states invariants (construction vs convention), names extension points, and
closes with what was not closed. Notes are corrected against the tree; the tree is not
forced to match a stale note.

When comparing with `../randombit-botan`, say so and quote a pin. A C++ type that does not
exist here is not an implicit to-do unless `architecture/upgrade-randombit.md` lists it.

Feature flags, SCAN names, and wiki signatures are observed in `dub.json`,
`source/botan/constants.d`, `source/botan/all.d`, and the consumer trees, not taken from
README marketing lists.
